# Portfolio

This is a minimalist personal portfolio built with Python and Flask.

## Run Locally

1. Install the Python dependency:

   `pip install -r requirements.txt`

2. Start the app:

   `python index.py`

3. Open the site in your browser:

   `http://127.0.0.1:5000`

## What’s Included

The first iteration ships with a reusable layout shell, a responsive navigation bar, and global styling that applies the requested color palette and typography across the page.
